# FORMA — AI-assisted fitness coaching

FORMA is a web platform designed to help coaches plan training and follow client progress between sessions. It brings workout plans, check-ins, and coaching feedback into one place.

## What the project covers

- **Client workspace:** Follow a training plan and record progress and check-ins.
- **Coach workspace:** Organize client programs and review updates.
- **AI-assisted coaching:** Explore how AI can support workout planning and help summarize client updates for coach review.

## My contribution

I developed the product around separate client and coach workflows and iterated on the interface through testing. FORMA is in development.
